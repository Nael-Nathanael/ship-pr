# Origin

The workflow this skill is built from, in the author's own words. When the
skill and this text disagree, this text states the intent.

> branch out from default branch, and set open PR as definition of done. PR should have a proper description that's easy to understand by everyone, include gif/video and photos as proof. full implementation should use Claude Code's flow: explore first, YAGNI system, and maximize reusability, modularity, set minimum coupling and max coherence. Right tool for the right job, and DRY (do not repeat yourself) and do not reinvent the wheel. Explore first, plan it, self-challenge the plan using same/better model on independent subagent. When going to implementation mode, setup checklist of tasks first. Also include the unit test, e2e test, integration test for the implementation when it's applicable. When done, do crosscheck with the plan artifact. If possible, run locally and do UI testing walktrhough for the changes using playwright. Finally, open PR with evidences. Until all those steps are fulfilled, you should never say it's "done".
